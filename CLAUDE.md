# CLAUDE.md

As instruções de uso da marca Parô estão no [AGENTS.md](AGENTS.md).

Leia esse arquivo antes de gerar qualquer tela, apresentação, documento ou peça da marca.

Quando o trabalho envolver interface, leia também o [DESIGN.md](DESIGN.md).

## Resumo mínimo

- Não redesenhe logotipo, símbolo ou grafismos. Use os arquivos deste repositório.
- Cores da marca: creme `#FFF9E3`, céu `#C3D2D7`, azul `#6EA8FF`, asfalto `#32312C`.
- Verde, âmbar e vermelho são exclusivos para status de ocupação de vaga. Nunca decorativos.
- Fonte única: Satoshi. JetBrains Mono só para código.
- Sem emojis. Ícones da família [Lucide](https://lucide.dev/).
- O Parô entrega previsão, não garantia. Nenhum texto promete encontrar vaga.
- Não crie campos para placa, CPF, nome completo ou telefone.
